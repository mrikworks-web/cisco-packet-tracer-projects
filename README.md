# Cisco Packet Tracer Projects

A collection of network simulation projects created using Cisco Packet Tracer.

## Enterprise Network Infrastructure

### Overview
Designed and configured a multi-department enterprise network using Cisco Packet Tracer.

### Technologies & Concepts
- VLANs
- Inter-VLAN Routing
- Trunking
- IPv4 Addressing

### Project File
- `Enterprise-network.pkt` — Cisco Packet Tracer topology and configuration

### Network Configuration
The project includes separate VLANs with inter-VLAN communication, DHCP address assignment, and router-based network services.

### Verification
Connectivity was tested using:
- `ping`
- `ipconfig`
- `show ip interface brief`
- `show ip dhcp pool`
- `show ip dhcp binding`
- `show interfaces trunk`
